# 🏝️ Battle Island
**Developed by Fariha Zahin**
A fast-paced top-down action survival game where you fight on tropical islands, defeat waves of enemies, collect resources, upgrade your soldier, unlock powerful weapons, and conquer **20 unique islands**.
---
## 🎮 Game Modes
### 🏝️ Island Campaign
Conquer 20 islands with increasing difficulty. Defeat enemies, face bosses, and become the **Island Legend**.
### ⚔️ Classic Mode
Endless survival. Kill as many enemies as possible and chase your high score.
### ⏱️ Time Rush
Exactly 2 minutes. 20 escalating levels.
Level 1 = 5 kills → Level 20 = 100 kills.
Can you reach Level 20?
---
## ✨ Features
- 20 unique islands with different environments
- Multiple enemy types (Runner, Tank, Shooter, Healer, Assassin + Bosses)
- Weapon system (Pistol, Rifle, Shotgun, Plasma, Rocket)
- Upgrade system (Health, Speed, Damage, Boost)
- Coins & Gems progression
- Achievements system
- Combo system
- Mobile-friendly joystick + action buttons
- Keyboard support
- Sound effects + background music
- Save system (progress is automatically saved)

## 🕹️ Controls
### Mobile
- Left Joystick → Move
- 🎯 Fire button → Shoot
- ⚡ Boost button → Speed boost
- 💣 Special button → Special attack (when charged)
### Keyboard
- `W` `A` `S` `D` or Arrow Keys → Move
- `Space` → Shoot
